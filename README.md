# PurpleSchool

Простые учебные проекты на Golang для расчёта индекса массы тела (IMT)

## Проекты
1. IMT - индекс массы тела

## Требования

- Установленный go версии 1.22.1

## Запуск

### Запуск приложения в dev-режиме

```bash
go run main.go
```

### Сборка приложения

```bash
go build
```

### Сборка модуля

```bash
go mod init purpleschool/imt
```

### Запуск бинарника

```bash
./imt
```
