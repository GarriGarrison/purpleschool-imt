# IMT (PurpleSchool)

Простой учебный проект на Golang для расчёта индекса массы тела (IMT)

## Требования

- Установленный go версии 1.22.1

## Запуск

### Запуск приложения в dev-режиме

```bash
go run main.go
```

### Сборка приложения

```bash
go build
```

### Сборка модуля

```bash
go mod init purpleschool/imt
```

### Запуск бинарника

```bash
./imt
```
